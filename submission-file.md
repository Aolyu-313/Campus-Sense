## Introduction to Application

CampusSense is a Flutter mobile application designed to support campus environmental awareness and feedback. It fits the Connected Environments theme by linking users, mobile devices, campus spaces, environmental data, and backend services. The app helps users understand the micro-environment around them and provides a simple way to report comfort-related issues in different campus locations.

The application contains multiple interactive screens. The dashboard shows a campus micro-environment comfort score, location information, weather data, air quality indicators, and device context. The report page allows users to submit feedback by selecting a scene, such as study, rest, walk, or commute, and choosing tags such as comfortable, quiet, good for study, too hot, too cold, too noisy, or poor air. The history page supports review of previous feedback records, while the nearby page supports exploration of local campus feedback. The settings page provides backend service information, health check, anonymous device identity, demo location, language options, and data source explanation.

The app uses Flutter and Dart for the mobile interface and communicates with a Spring Boot backend service through REST API requests. The backend supports environmental data handling, report submission, history records, comfort score calculation, reverse geocoding, weather data, and air-quality data. Overall, CampusSense demonstrates how mobile interaction can support repeated engagement with campus environmental conditions.
